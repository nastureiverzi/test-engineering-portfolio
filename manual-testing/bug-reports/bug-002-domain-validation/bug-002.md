* **Date Raised:** N/A

* **Environment:** Staging

### Defect Summary
On user registration, an email address without a domain (testEmail@gmail) is allowed

### Steps to Reproduce
1. Go to https://automationexercise.com/
2. Click on "Signup / Login" menu option
3. On the Login page, locate the "New User Signup!" section
4. Fill in username and an email address without a domain.
5. Click "signup" button

### Actual Result
User is redirected to the registration form page

### Expected Result
The browser displays a tooltip near the email address input indicating that the email address given is invalid. User remains on the signup page.
