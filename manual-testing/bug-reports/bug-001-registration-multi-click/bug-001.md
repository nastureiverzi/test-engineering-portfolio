# Bug-001

* **Defect ID:** BUG-001
* **Defect Description:** Registration fails with multiple clicks on "create account" button
* **Date Raised:** N/A
* **Defect Severity:** Major
* **Defect Priority:** Medium
* **Environment:** Staging
* **Platform:** Desktop

---

### Defect Summary
When the user clicks the "Create account" button multiple times, the system sends multiple signup requests, one per click. The requests fail with 500 errors

### Steps to Reproduce
1. Go to https://automationexercise.com/
2. Click on "Signup / Login" menu option
3. On the Login page, locate the "New User Signup!" section
4. Fill in username and email address
5. Click "signup" button
6. Fill in required form details. 
7. Click "create account" button at least 5 times

### Actual Result
Registration fails with 500 error. A separate request is sent for each click on the "create account" button.

### Expected Result
User account is successfully registered and the user is redirected to the homepage.
