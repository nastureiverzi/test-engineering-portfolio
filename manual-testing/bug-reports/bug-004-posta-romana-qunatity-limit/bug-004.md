# Bug-004

* **Defect ID:** BUG-004
* **Defect Description:** "Cantitate" Input field on "Calculator Tarife" page has no character limit
* **Date Raised:** N/A
* **Defect Severity:** Major
* **Defect Priority:** High
* **Environment:** Live

---

### Defect Summary
Due to the lack of character limit on the "Cantitate" input field on "Calculator Tarife" page, the user has the ability to introduce a very large number, which can lead to "Infinity" value on the calculator.

### Steps to Reproduce
1. Go to https://www.posta-romana.ro/calculator-de-tarife.html
2. Navigate to the "Intern" menu
3. Expand "Scrisori si carti postale"
4. Click on "Corespondenta interna"
5. In the "Cantitate" input field add 100 or more numerical characters

### Actual Result
The input field does not have a character limit

### Expected Result
The input field should have a character limit
